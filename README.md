# Actividad 1 - Tema 2 | Programación Web

## Descripción
Este repositorio contiene los ejercicios prácticos realizados en clase para la Actividad 1 del Tema 2 de la materia de Programación Web. Cada ejercicio trabaja conceptos de HTML, CSS y JavaScript de forma progresiva.

## Contenido
- **14 ejercicios** (`ejercicio1.html` a `ejercicio14.html`)
- Carpeta `css/` con los estilos de cada ejercicio
- Carpeta `js/` con los scripts de los ejercicios interactivos
- Carpeta `img/` con las imágenes utilizadas
- `index.html` como menú principal con enlaces a todos los ejercicios
